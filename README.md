# 🌟 STUDENT FORM — Yellow World Edition
### *Warm design. Smart validation. Instant records.*

💛 A vibrant, responsive student registration web application built with **Tailwind CSS** and **Vanilla JavaScript** to collect, validate, and manage student records dynamically in real time.

---

### ✨ Key Features

- 👤 **Personal Details** — Clean inputs for Student Name and Age
- ⚧ **Single-Choice Gender Selection** — Grouped Male & Female radio options
- 📚 **Course Dropdown** — Easy course selection menu (JavaScript, Python, Java, and more)
- 📧 **E-mail Capture** — Dedicated e-mail input field
- 🛡️ **Smart Form Validation** — Prevents blank submissions with an instant alert reminder
- ⚡ **Dynamic Record Table** — Instantly adds submitted entries into a structured table without page reloads
- 🗑️ **One-Click Delete Action** — Remove individual student rows anytime with a single click

---

### 🛠️ Tech Stack

`HTML5` · `Tailwind CSS` · `JavaScript (DOM Manipulation)`

---

### 🔄 How It Works

**Fill Details → Validate Inputs → Save to Table → Manage Records**

1. Enter all required student details in the warm yellow-themed registration card.
2. Click **Save** to trigger JavaScript input validation and append a new row to the live table below.
3. Click **Delete** under the **Action** column whenever you need to remove an entry.
